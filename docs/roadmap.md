# Next milestones

These are future tasks, not completed features.

## 1. Explain and own the present implementation

- Complete the three exercises in the interview guide.
- Review one source record independently and record the evidence.
- Run the demo and explain every row in its event audit.
- Make one meaningful improvement with a test and a clear commit message.

Done means another person can ask about an input, an execution assumption or a rejection and receive a clear explanation without relying on memorized phrases.

## 2. Improve the data before adding strategies

- Expand the original dated release/forecast panel without inspecting each event's return during selection.
- Collect intervening forecast revisions and distinguish management guidance from independent analyst expectations.
- Verify first publication dates, historical corporate actions and tradable universe membership.
- Add reproducible source-specific parsing only where document structure supports it; retain manual review for ambiguous tables.

Done means the accepted event set is larger and each verification flag has explicit supporting evidence. More rows alone is not sufficient.

## 3. Design a new validation experiment

- Freeze a new protocol and genuinely uninspected evaluation period.
- Plan inference for repeated events within issuers and overlapping event windows.
- Review whether sample size and dependence permit meaningful uncertainty estimates.
- Refine executable peer selection, auction assumptions and settlement constraints.

Done means a reviewer can tell which claims are established, which are exploratory and which remain unknown. Do not optimize the old sample until it appears profitable.
