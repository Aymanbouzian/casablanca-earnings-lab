## LinkedIn project announcement draft

I turned a Casablanca stock-market research idea into a reproducible Python project: can earnings surprises predict useful returns after trading costs?

The first dataset did not establish an alpha. That became the most useful part of the investigation. An old forecast could create an apparent surprise, different profit definitions could invalidate a comparison, and trading costs materially changed the result.

The project includes source-linked observations, explicit exclusion reasons, a portfolio ledger, liquidity-constrained exits and a synthetic demo that runs offline. I developed it with AI assistance and am working through the implementation and research decisions myself.

I am interested in feedback on the data assumptions and execution model, and in internships involving quantitative research, financial data or Python engineering.
